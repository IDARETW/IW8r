## M1: edit → save → reopen (done)

**Goal.** A mapper opens a small IW8 scene, moves a brush on the grid, changes an entity property, undoes and redoes,
saves a copy, and reopens it with the edits intact. Untouched geometry, material references and unknown fields must
survive. At least one real IW8 format path must be exercised.

**Scenes.**
- `samples/iw8/iw8_sample_room.map` (generated by `tools/make_iw8_sample_room.py`). 7 brushes, 1 patch, 11 entities.
  Materials and the xmodel are real Replay 1.20 names from stock `mp_backlot2` dumps. Classnames come from stock
  `mp_hideout` and its compiled spawns. It contains deliberate unknown fields: `layer`, `contents detail;`,
  `toolFlags splitGeo;`, vertex colours, and an `editor_note` key.
- Stock IW8 data: `mp_hideout` MapEnts (ACTS dump on disk: 2,660 entities, 501 compiled spawns) and `mp_shipment`,
  read live through ACTS by the editor (611 entities, 611 spawns).

## M2.1 result (2026-11-08): edited entities written into a real Replay 1.20 fastfile, verified offline

`tools/m2_rebuild_mapents.ps1 -Zone mp_shipment -Ents <edited .ents>` runs the whole path in about 100 s, entirely under `out\`.
The Replay install is only read, and its timestamps are checked.
- `src/core/iw8_dump.*` reads and writes the x64-zt `IW8D` container. On stock `mp_shipment` `map_ents` (3,185 records),
  record 0 is the 1,032-byte `MapEnts` header with `numEntityChars` at +16, and record 2 is the NUL-terminated entity
  string, byte-identical to the ACTS dump. The container round-trips byte for byte. The write-back replaces only those two
  values; the other 3,183 records stay byte-identical (`iw8r_tests`: `iw8d_mapents_roundtrip_and_writeback`).
- Edit used: the first `script_model` (entity 379) moved +16 X (`-696 1616 16` → `-680 1616 16`), plus a new
  `script_noteworthy`. x64-zt `buildzone` wrote 8,848 assets. The payload is 25 bytes larger than the unedited control
  rebuild, exactly the entity-string growth.
- Validation of the rebuilt zone: x64-zt `verifyzone` passed (every byte consumed). ACTS `--test` through Replay's own
  loaders gave 10,478 assets, 51 tested, 0 failed, the same as the stock zone. ACTS `-a map_ents` read-back diffed
  against the edit gives 0 changes.
- **In game: NOT VERIFIED.** The owner's test is to put `out\…\out\mp_shipment.ff` into a scratch copy of the Replay install
  (keeping the stock zone), load mp_shipment, and look for the crate/model 16 units east of its stock spot.

## M5.1 result (2026-11-08): the editor builds Replay 1.20 map zones, verified offline

- `src/core/compile_iw8.*` (`iw8r compile <map> -o <dir> --map <id>`) writes the extraction folder of
  [research/15](research/15_iw8_extraction_contract.md) plus the four extra inputs found in
  [research/17](research/17_x64zt_buildextraction.md) §4 (`zone_source/<id>.zone`, `triangle_contents`, `"sky":""`,
  an all-null impact table so Replay keeps its stock impacts). Brush faces and tessellated patches become world surfaces;
  solid brushes become collision; point entities of the converter's closed class list become `.ents`.
- x64-zt branch `iw8radiant/build-extraction` (commit `190aa793`, not pushed) adds `zonetool -game iw8 buildextraction`.
- In the editor, Compile > Compile Map (F7) runs extraction → buildextraction → ACTS `--test` on every zone, in the
  Compile panel, without blocking editing. On the sample room: 8 surfaces, 74 triangles, 6 collision brushes; the five zones
  load through Replay's own loaders (`mp_*.ff` 792 assets loaded, 19 tested, 0 failed; the other four 0 failed).
- Compile > Deploy installs the package into `<game>/mods/mw120r/maps/<id>/` (staged copy, SHA-256, backup to
  `.proxy/backups`, refuses while Replay runs); Undo Last Deploy restores. Tested on a scratch folder only.
- Brush entities: triggers of the converter's class list and `script_brushmodel` compile as brush models `*N`
  (collision submodel + leaf node, `brush_models` range, `"model" "*N"`; trigger brushes use IW3 trigger contents
  `0x8000001`). Test map `out/m5/iw8_sample_room_bm.map` (trigger + door): x64-zt kept 5 brush models (2 are its own Replay
  template entities) with 4 native collision shapes, passed its structural checks, and ACTS loaded the five zones with 0 failed.
- Limits: every surface uses one grey material; stock models on `script_model` are dropped with a warning; other brush
  entity classes (`func_*`) are left out with a warning; no lighting bake. See
  [research/18](research/18_x64zt_stock_assets.md) for the stock-asset route.
- **In game: NOT VERIFIED.** Owner test: F7, Compile > Deploy, start Replay, Local Play, F6, pick the map.

## What is left (2026-11-14)

M2.2 (the spawn list written back from spawn entities) is done offline; see ROADMAP 6.1 and 11.2. What is left comes
from [HANDOVER.md](HANDOVER.md) sections 4 and 5.

**Only the game can settle these** (owner checks, in this order; steps in [TEST_CHECKLIST.md](TEST_CHECKLIST.md)):
1. An installed stock edit loads (the toon filter on Shipment, File > Install Edited Stock Map Into Game). Every stock
   map edit depends on it.
2. An own map looks like View > Game Lighting, with Bake lightmaps off and on.
3. A stock door carried into an own map opens.
4. A stock map rebuilt with removed world geometry: the object is gone and you walk through where it was.
5. Copied loot, doors and extraction sites on Quarry work like the originals.
6. Optional: nothing is missing on a map built with the occlusion bake.

**Not built, or built in part:**
- Web page: patch vertex editing; the full Vision Editor.
- Occlusion: occluders that are not boxes; local updates of a stock map's occlusion data.
- Viewport: highlights of own materials with a specular map; volumetric fog is uncalibrated and off.
- Streamed Warzone tiles cannot be edited (the client refuses unsigned tiles).
- A turned stock sun keeps the old sun in the baked bounce light.
- Items the game must answer first (reverb zones, killstreak airspace, intro cameras) are listed in ROADMAP.md.
- Ground War scale maps are out of scope.
