- Size: partial, not proven. Best value 9800, bounds 9769 (lower, useImmediateContext byte) to 9804 (upper, local `drawSlot` frame gap). Candidate from the element arithmetic below.

Both are on the 9808 stride. Difference 43528 - 33728 = 9800 is cmdCount's offset from the QWORD.
- Evidence for the cmdBuf object: `R_DrawSlot_BindCurrentContext@0x1418E3450` writes `*(QWORD*)drawSlot = g_gfxImmediateContext` and `*(BYTE*)(drawSlot + 9768) = 1`. `drawSlot` is a 9800-byte stack local of `RB_RunDrawList` (`__int64[1225]`, next local at +9804). So the GfxCmdBuf-shaped object has useImmediateContext at +9768, device at +0.
- Not closed: whether the element QWORD at +33728 is element+0 (so cmdBuf is element+0 and cmdCount directly follows it at 9800). Its writer was not found in `R_DrawShadowMapWorkerSlice@0x1418FA4B0` (no 83C0h displacement), and no other writer was traced.
- Members: device +0 (QWORD, confirmed write; pointer type unconfirmed), useImmediateContext +9768 (bool, confirmed write). Unconfirmed: cmdBufIndex, cmdList, descState (+24, 9744 from A184/A071, arithmetic only: 24 + 9744 = 9768), constantBufferAllocations (24 bytes, end at 9800 if 7 bytes of gap).
- Verdict: partial. Not absent: the struct is held by value in the element (A186).
- Problems: no tool errors. The game-test descState size 9064 does not fit the +9768 flag, so game-test's layout is not used.
