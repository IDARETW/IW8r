# A120

Read-only pass over the Demonware wrapper structs. Nothing was written to IDA. Proposals are in `E:\IW8-Radiant\out\ida_types\proposals\A120.json`.

Key evidence: `DWWrappers::init` (0x140F6B880) and its tail place every DW wrapper slot 16 bytes apart (`lea rcx,[rdi+N]` followed by the `__init` call), so BaseDWWrapper is 16 bytes (vptr at +0, owner at +8). Each slot gap gives that wrapper's size.
